Airport codes

On a ticket or a baggage tag, ESB means Esenboğa International Airport. Pilots and air traffic controllers use a different, four-letter ICAO code: LTAC. ICAO codes that begin with L belong to southern Europe, Israel and Turkey. How the two kinds of code differ.

Where it is

The airport lies at 40.1281° N, 32.9951° E. It stands 952 metres (3,125 feet) above sea level.

Which way the runway points

The longest runway, 03C/21C, lies roughly south-west to north-east. An aircraft using the end marked 03C is heading about 30° on the compass, and one using the other end about 210°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. All 3 runways here point the same way, so they can be used side by side.
