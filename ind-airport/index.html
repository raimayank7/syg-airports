Airport codes

On a ticket or a baggage tag, IND means Indianapolis International Airport. Pilots and air traffic controllers use a different, four-letter ICAO code: KIND. ICAO codes that begin with K belong to the mainland United States. How the two kinds of code differ.

Which way the runway points

The longest runway, 05L/23R, lies roughly south-west to north-east. An aircraft using the end marked 05L is heading about 50° on the compass, and one using the other end about 230°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. The 3 runways point in 2 different directions, which gives a choice when the wind swings round.
