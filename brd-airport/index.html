Airport codes

On a ticket or a baggage tag, BRD means Brainerd Lakes Regional Airport. Pilots and air traffic controllers use a different, four-letter ICAO code: KBRD. ICAO codes that begin with K belong to the mainland United States. How the two kinds of code differ.

Which way the runway points

The longest runway, 16/34, lies roughly north to south. An aircraft using the end marked 16 is heading about 160° on the compass, and one using the other end about 340°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. The 3 runways point in 3 different directions, which gives a choice when the wind swings round.
