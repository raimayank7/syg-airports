Airport codes

On a ticket or a baggage tag, PAE means Seattle Paine Field International Airport. Pilots and air traffic controllers use a different, four-letter ICAO code: KPAE. ICAO codes that begin with K belong to the mainland United States. How the two kinds of code differ.

Which way the runway points

The longest runway, 16R/34L, lies roughly north to south. An aircraft using the end marked 16R is heading about 160° on the compass, and one using the other end about 340°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. All 2 runways here point the same way, so they can be used side by side.
