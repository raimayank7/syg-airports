Airport codes

On a ticket or a baggage tag, FUG means Fuyang Xiguan Airport. Pilots and air traffic controllers use a different, four-letter ICAO code: ZSFY. ICAO codes that begin with Z belong to China, Mongolia and North Korea. How the two kinds of code differ.

Which way the runway points

The longest runway, 03/21, lies roughly south-west to north-east. An aircraft using the end marked 03 is heading about 30° on the compass, and one using the other end about 210°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it.
