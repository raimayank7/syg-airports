The letter X in numbers

There are 676 possible three-letter codes that begin with X, from XAA to XZZ. 91 of them, 13%, belong to an airport in this data, and 35 of those airports have scheduled airline flights and a page of their own here. Codes beginning with X make up 1.0% of all 9,053 codes on this site, where an even share for each of the 26 letters would be 3.8%.

Which countries use X most

The countries with the most codes on this page are Canada (15), Burkina Faso (14), China (12), Australia (8). Canada holds 16% of the codes that start with X, against 5% of all codes, so this letter leans strongly towards it. The United States, which has 22% of all codes, has only 8% of those beginning with X. Very few city names begin with X, so in most of these codes the X is a filler letter and not an initial.

Do the letters match the place?

In 12% of the codes on this page, the city or the airport name itself begins with X. In the rest, the X comes from somewhere else: an older name of the city, the name of the airport and not the city, a letter added because the obvious code was taken, or a national habit. The most common second letter is M (11 codes, from XMA to XMZ), and no code in the data begins with XH or XO or XV or XX.

Large airports whose code begins with X

Birjand (XBJ), Xi'an (XIY), Xiamen (XMN), Haidong (Huzhu Tu Autonomous County) (XNN), Palmerola (XPL).

Using this list

The table is in alphabetical order of the code. Type in the filter box to narrow it by code, airport, city or country. A code with a link opens that airport's page, with its runways, height, local time and distances. A code without a link belongs to an airfield with no scheduled airline flights in the data. If the three letters on your ticket are not here, they may be a city code that covers several airports, such as LON or NYC.
