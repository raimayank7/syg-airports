The letter N in numbers

There are 676 possible three-letter codes that begin with N, from NAA to NZZ. 316 of them, 47%, belong to an airport in this data, and 135 of those airports have scheduled airline flights and a page of their own here. Codes beginning with N make up 3.5% of all 9,053 codes on this site, where an even share for each of the 26 letters would be 3.8%.

Which countries use N most

The countries with the most codes on this page are United States (54), Australia (25), Russia (18), China (15).

Do the letters match the place?

In 61% of the codes on this page, the city or the airport name itself begins with N. In the rest, the N comes from somewhere else: an older name of the city, the name of the airport and not the city, a letter added because the obvious code was taken, or a national habit. The most common second letter is A (24 codes, from NAA to NAZ), and no code in the data begins with NX.

Using this list

A code with a link opens that airport's page, with its runways, height, local time and distances. A code without a link belongs to an airfield with no scheduled airline flights in the data.
