The letter R in numbers

There are 676 possible three-letter codes that begin with R, from RAA to RZZ. 330 of them, 49%, belong to an airport in this data, and 137 of those airports have scheduled airline flights and a page of their own here. Codes beginning with R make up 3.6% of all 9,053 codes on this site, where an even share for each of the 26 letters would be 3.8%.

Which countries use R most

The countries with the most codes on this page are United States (84), Australia (24), Argentina (15), Brazil (13).

Do the letters match the place?

In 64% of the codes on this page, the city or the airport name itself begins with R. In the rest, the R comes from somewhere else: an older name of the city, the name of the airport and not the city, a letter added because the obvious code was taken, or a national habit. The most common second letter is B (24 codes, from RBA to RBZ).

Using this list

The table is in alphabetical order of the code. Type in the filter box to narrow it by code, airport, city or country. A code with a link opens that airport's page, with its runways, height, local time and distances. A code without a link belongs to an airfield with no scheduled airline flights in the data.
