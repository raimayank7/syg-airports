Airport codes

On a ticket or a baggage tag, SAW means Istanbul Sabiha Gökçen International Airport. Pilots and air traffic controllers use a different, four-letter ICAO code: LTFJ. ICAO codes that begin with L belong to southern Europe, Israel and Turkey. How the two kinds of code differ.

Which way the runway points

The longest runway, 06R/24L, lies roughly south-west to north-east. An aircraft using the end marked 06R is heading about 60° on the compass, and one using the other end about 240°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. All 2 runways here point the same way, so they can be used side by side.
