Which way the runway points

The longest runway, 12/30, lies roughly north-west to south-east. An aircraft using the end marked 12 is heading about 120° on the compass, and one using the other end about 300°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. The 2 runways point in 2 different directions, which gives a choice when the wind swings round.
