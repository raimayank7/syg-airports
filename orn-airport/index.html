Airport codes

On a ticket or a baggage tag, ORN means Oran Es-Sénia (Ahmed Ben Bella) International Airport. Pilots and air traffic controllers use a different, four-letter ICAO code: DAOO. ICAO codes that begin with D belong to West Africa. How the two kinds of code differ.

Where it is

The airport lies at 35.6206° N, 0.6225° W. It stands 90 metres (295 feet) above sea level.

Which way the runway points

The longest runway, 07L/25R, lies roughly west to east. An aircraft using the end marked 07L is heading about 70° on the compass, and one using the other end about 250°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. All 2 runways here point the same way, so they can be used side by side.
