Airport codes

On a ticket or a baggage tag, SJT means San Angelo Regional Mathis Field. Pilots and air traffic controllers use a different, four-letter ICAO code: KSJT. ICAO codes that begin with K belong to the mainland United States. How the two kinds of code differ.

Which way the runway points

The longest runway, 18/36, lies roughly north to south. An aircraft using the end marked 18 is heading about 180° on the compass, and one using the other end about 360°. Which end is in use on a given day depends on the wind, since aircraft land and take off into it. The 3 runways point in 3 different directions, which gives a choice when the wind swings round.
